# Help build the Accessibility Knowledge Base

Help build the [WP Accessibility Knowledge Base](https://wpaccessibility.org/), the WordPress community's accessibility documentation. You can write a new page on a topic that interests you, review existing content, or report an error you notice.

- **Reference:** [How to contribute](https://wpaccessibility.org/docs/about/contribute/)
- **Connect:** Join [#accessibility-docs](https://wordpress.slack.com/archives/C6PK2QCTY) on Slack and introduce yourself

## Steps

1. **Explore.** Check the [WP A11y docs project board](https://github.com/orgs/wpaccessibility/projects/3) and [wpaccessibility.org](https://wpaccessibility.org/) to see what exists and what's still needed.

2. **Choose how to contribute.** You can write new documentation, [review content](https://wpaccessibility.org/docs/about/contribute/review/), or [report an error](https://wpaccessibility.org/docs/about/contribute/report-error/). If you want to write new documentation, contact the project leads first so the topic can be assigned. For an existing documentation task, check the related GitHub issue and coordinate with the team before making changes. New content written without contacting the leads first will not be reviewed.

3. **Write, update, or review.** If you're writing a new page, cover the topic in your own words, follow the structure in the [Write documentation](https://wpaccessibility.org/docs/about/contribute/write/) guide, and link to authoritative sources rather than restating them. Use AI only to translate or check your English, not to write the content.

   If you're updating an existing page for an assigned task, follow the related GitHub issue and share your proposed changes through an appropriate channel listed in Step 5, such as a comment on the issue or a pull request.

   If you're reviewing a proposed documentation pull request, follow the [Review documentation](https://wpaccessibility.org/docs/about/contribute/review/) guide to share feedback on the proposed changes. If you find a problem in already published documentation, report it using the next step.

4. **Report an error (alternative).** If you've spotted a problem instead, follow the [Report an error](https://wpaccessibility.org/docs/about/contribute/report-error/) instructions. Give enough detail for the team to locate and investigate it. Reporting an error is a valid contribution on its own; you do not need to write a new page.

5. **Share your contribution.** Share a new draft or proposed documentation update through the [contact form](https://make.wordpress.org/accessibility/accessibility-knowledge-base-contact/), [#accessibility-docs](https://wordpress.slack.com/archives/C6PK2QCTY), a comment on the related [GitHub issue](https://github.com/wpaccessibility/wp-a11y-docs/issues), or a [pull request](https://wpaccessibility.org/docs/about/contribute/github/pull-requests/). For reviews and error reports, use the submission methods described in their respective guides.

## Contribution checklist

- Chose a writing, reviewing, or error-reporting task and followed the relevant instructions
- If writing new documentation, contacted the project leads and received an assignment before starting; if updating existing documentation, coordinated through the relevant issue or with the team
- Completed the chosen contribution: wrote a page using the required structure, reviewed a documentation pull request, improved existing documentation, or reported an actionable error
- Shared the draft, proposed change, review feedback, or error report through the appropriate channel

## What happens next

For a new page or proposed documentation change, a reviewer may suggest revisions before it's merged or published on the Knowledge Base. If you shared review feedback or reported an error, the team may investigate, respond with questions, or address the issue. If you don't hear back, follow up in [#accessibility-docs](https://wordpress.slack.com/archives/C6PK2QCTY).

When you're ready, pick up another topic or settle into an area you can develop further.

## Help

Stuck? Check the [getting help guide](https://make.wordpress.org/handbook/pathways/before-you-begin/#getting-help), then ask in [#accessibility-docs](https://wordpress.slack.com/archives/C6PK2QCTY).
